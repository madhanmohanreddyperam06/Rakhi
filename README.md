# Raksha Bandhan Celebration App

A festive React application for celebrating Raksha Bandhan with cinematic animations and interactive elements.

## Setup

```bash
npm install
npm run dev
```

Build for production:
```bash
npm run build
```

## Features

- Welcome screen with animated background and diyas
- Memory slideshow with smooth transitions
- Distance visualization between cities
- Rakhi selection with custom photo
- Tilak ceremony with GIF animation
- Rakhi tying with GIF animation
- Sweet selection
- Gift box reveal
- Final celebration

## Tech Stack

- React 18.2.0
- Framer Motion 10.16.0
- Vite 4.3.9
- CSS3
